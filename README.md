# 🚗 Automobile Sales Analytics Dashboard | SQL + Power BI

## 📌 Project Overview

This project demonstrates an end-to-end Business Intelligence solution developed using **MySQL** and **Power BI**. The objective is to transform raw sales data into meaningful business insights through data cleaning, modeling, analysis, and interactive dashboard development.

The dashboard provides executives and business managers with a centralized view of key performance indicators (KPIs), product performance, regional sales trends, customer purchasing behavior, and revenue trends to support data-driven decision-making.

---

## 🎯 Business Objectives

- Monitor overall sales performance.
- Track key business KPIs.
- Identify top-performing vehicle models.
- Analyze dealer city performance.
- Understand customer purchasing behavior.
- Monitor monthly revenue trends.
- Build an interactive dashboard for business decision-making.

---

## 🛠️ Tools & Technologies

- **Power BI**

## 📂 Dataset

The project uses a **synthetic automobile sales dataset** created for educational and portfolio purposes.

The dataset contains three related tables:

| Table | Description |
|--------|-------------|
| Customers | Customer demographic information |
| Vehicles | Vehicle master data |
| Sales | Sales transaction records |

## 🧹 Data Preparation

The following data validation and cleaning steps were performed before visualization:

- Checked NULL values
- Removed duplicate records
- Verified referential integrity
- Removed orphan sales records
- Corrected inconsistent values
- Created reporting table (`real sales`)
- Built Power BI relationships
- Created DAX measures
- Created Calendar (Date) table


# 💡 Key Business Insights

- Generated **₹6,074M** in revenue during the analysis period.
- Sold **4,996** vehicles across multiple cities.
- Revenue is concentrated among a few high-performing vehicle models.
- Dealer city analysis highlights the strongest regional markets.
- Customer payment preferences indicate significant dependence on financing.
- Fuel type analysis provides insight into customer vehicle preferences.
- Monthly trend analysis reveals seasonal fluctuations in revenue.
